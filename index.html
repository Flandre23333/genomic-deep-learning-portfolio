Research context

Conserved non-coding regions are difficult to see—and biologically important.

Most of the human genome does not encode proteins, yet parts of this “dark matter” carry regulatory and evolutionary signals. The project asks whether a genomic language model can distinguish highly conserved from weakly conserved long non-coding RNA windows on chromosome 1.

02 / Method deep dive

A reproducible path from coordinates to candidates.

01

Build the evidence

Align three genomic sources

Processed lncRNA annotations define the regions of interest; the GRCh38 FASTA provides nucleotide sequence; and phastCons bigWig scores quantify evolutionary conservation for each sampled window.

  • Processed GTF annotations
  • Chromosome 1 FASTA
  • 100-species conservation scores
02

Construct the task

Window, label, and balance

Sliding 512 bp windows are labelled from phastCons quantiles. Low- and high-conservation tails form the binary task while ambiguous middle windows are left out, producing a clearer and balanced learning signal.

  • 128 bp stride
  • P30 / P70 labelling
  • 1:1 class sampling
03

Adapt the model

GPN backbone, custom head

The pretrained songlab/gpn-brassicales representation is pooled and passed through LayerNorm and an MLP classifier. Reverse-complement augmentation teaches strand robustness without changing the biological label.

  • Global sequence pooling
  • LayerNorm + MLP
  • Reverse-complement augmentation
04

Train deliberately

Freeze first, then unfreeze

Training begins with the classifier head while the pretrained backbone is frozen, then opens the full network with separate learning rates. AMP reduces GPU memory use, and checkpoints preserve both the best and final model states.

  • 3 frozen-head epochs
  • Head LR 1e−3 · base LR 2e−5
  • Mixed precision + checkpointing

Coordinate-based fine-tuning

From curated gene sets to a second evaluation path.

The fine-tuning pipeline accepts chromosome/start/end/label coordinate files, creates fixed-length positive and negative windows, optionally samples background negatives with PyRanges, and persists an auditable train/validation/test split as JSONL.
