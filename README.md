# Genomic Deep Learning — Personal Portfolio

This static portfolio presents Huan Zhang's independent GPN training and fine-tuning contribution from the UNSW COMP3900 team capstone, *Deep Mining the Genome's Dark Matter*.

## Public scope

The site intentionally includes only:

- GPN training and fine-tuning methodology authored by Huan Zhang
- Aggregate experiment metrics
- Result figures committed as part of that contribution
- A transparent description of contribution boundaries

It excludes the private repository history, team frontend/backend code, GPN-MSA work, UMAP work, datasets, checkpoints, internal paths, credentials, and other contributors' implementation.

## Preview

Open `index.html` directly or serve the directory with any static file server.

## Publishing

The project contains no build step and is compatible with GitHub Pages. Publish from the repository root on the `main` branch.
